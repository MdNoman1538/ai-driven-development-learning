# AI Driven Development Learning

An interactive site for learning **AI-driven development** through real projects. It focuses on the reasoning: the architecture, the decisions and the trade-offs behind each project, and how they were built with an AI coding agent.

Projects covered:
- **Finland Road Risk Intelligence:** an in-car, offline road-risk warning system built on Finnish crash data
- **projectViewer:** a live, explorable map of a codebase that records how it's built
- **This site itself:** how the learning app was built

## Run locally

```bash
npm ci
npm run dev        # http://localhost:4321/ai-driven-development-learning/
```
